# История изменений FiribStop UZ

## 3.0.0 — надёжнее, безопаснее и честнее
- Исправлена облачная синхронизация: SDK Supabase загружается только при явном подключении пользователя; URL проверяется, ключ `service_role` блокируется.
- Добавлена отсутствовавшая SQL-схема `supabase-schema.sql` с RLS-политиками, ограничением размера записи и изоляцией истории по `auth.uid()`.
- Усилен анализ URL: обнаружение некоторых типографских подмен брендов, невидимых символов и bidi-управляющих символов; тесты на ложные срабатывания.
- Исправлен OCR: ограничены размер/разрешение изображений, добавлено освобождение ресурсов даже при ошибке; библиотека подгружается по требованию.
- CSP разрешает только pinned CDN для функций OCR и опциональной Supabase-синхронизации; добавлена политика worker-src.
- Service Worker обрабатывает только same-origin ресурсы, API и внешние ресурсы оставляет сети; не отдаёт HTML вместо JS/CSS при офлайн-ошибке.
- Обновлены кеширование главных ресурсов, версия PWA и проверки синтаксиса.
- Антивирус/сканирование файлов и APK не возвращены.

## 2.9.0 — safer link analysis
- Удалены файловый/APK-сканер, карантин, база хешей и обновление базы вредоносных файлов.
- Добавлен отдельный локальный анализатор ссылок и регрессионные тесты.
- Добавлены HTTP smoke-тесты и ограничения публичной раздачи исходников на Node-хостинге.
- Уточнены предупреждения о том, что эвристики не доказывают безопасность.

## 2.8.0 — focused anti-scam release
- Убраны файло-сканер и функции карантина.
- Сохранены локальная проверка сообщений, ссылки, учебные сценарии, новости и PWA-режим.
